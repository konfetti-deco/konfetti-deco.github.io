# aachen-bus

Простая страница с ближайшими автобусами между остановками в Аахене:
Schanz (Jakobstraße) ↔ Bushof и Schanz (Jakobstraße) ↔ Kaiserplatz.

- Данные: [Transitous](https://transitous.org/) (расписание + реальное время DELFI / AVV), без ключей и регистрации.
- Один файл `index.html`, без сборки и зависимостей.
- Направления меняются в массивах `STOPS` и `ROUTES` в начале скрипта.
