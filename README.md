# Konfetti Deco — конструктор фотозон

Отдельный сайт конструктора, как LA CHEF: открывается в браузере, ставится на планшет как приложение со своим значком и работает без интернета.

Адрес: `https://konfetti-deco.github.io/` — отдельный сайт, не под 1400837-create.github.io (там живёт LA CHEF, и Chrome на Android считал Konfetti «уже установленным»).

## Установка на планшет

- **iPad (Safari):** «Поделиться» → «На экран „Домой“». Значок — буква D, название — Konfetti Deco.
- **Android (Chrome):** меню ⋮ → «Добавить на главный экран» (или «Установить приложение»).

После первого открытия сайт работает и без интернета: страница, значки и шрифты лежат в кэше.

## Где хранятся проекты

- **В браузере.** Последняя сцена, «Мои шаблоны» и картинки сохраняются в этом браузере сами.
- **Файлом.** «Файл → Скачать проект файлом» и «Открыть файл проекта…» — перенос между устройствами без интернета.
- **На всех планшетах (синхронизация).** «Проекты и шаблоны» → «Создать код» на первом планшете, на втором ввести этот код → «Подключить». Проекты, их картинки и «Мои шаблоны» видны на обоих.

Синхронизация идёт через ту же базу Firebase Realtime Database, что у LA CHEF (`la-chef-bbb7e`), по пути `rooms/<код комнаты>/loulou/…`. Код комнаты — единственный ключ доступа: 12 случайных знаков; кто знает код, тот видит проекты этой комнаты. Не публикуйте код.

### Если при подключении появляется «База Firebase не пустила»

В правилах базы нужно разрешить этот путь. Firebase Console → Realtime Database → «Правила», внутри `"rooms"` добавить:

```json
"rooms": {
  "$room": {
    "loulou": { ".read": true, ".write": true }
  }
}
```

(если в правилах для `rooms/$room` уже стоит `.read`/`.write: true`, ничего добавлять не нужно).

## Чего нет на сайте

- **«По фото»** — разбор фотографии делает Claude, поэтому эта функция есть только в версии на claude.ai.

## Обновление

Готовая страница — `index.html`. Исходники лежат в `source/`: `python3 build.py` собирает версию для claude.ai, `python3 build.py --site` — этот сайт (папка `site/`). Публикация — автоматически при каждом push в `main` (GitHub Actions → Pages).
